เขียนเป็นประโยคธรรมดา ว่า Product ทำอะไรได้หรือไม่ได้ ต้องตั้งค่า พัฒนาเพิ่ม หรือเชื่อมระบบลูกค้าตรงไหน

- ไฟล์ที่ขึ้นต้นด้วย `_` (เช่นไฟล์นี้) ระบบไม่ถือเป็น note: copy ไปตั้งชื่อใหม่แล้วแก้
- `support` เลือก 1 อย่าง: `full` ทำได้เลย · `config` ตั้งค่าอย่างเดียว · `custom` ต้องพัฒนาเพิ่ม · `integ` ต้องเชื่อมระบบลูกค้า · `none` ไม่รองรับ
- `service` เลือกชื่อจากรายการใน `kb/README.md`
- ถ้าความสามารถนี้มีเฉพาะบาง solution ให้เพิ่มบรรทัด `solution: CRM+ module, App project — Custom` ถ้าไม่ใส่ = ใช้ได้ทุก solution
- อ้างอิง note อื่นด้วย `[[folder/name]]`
- ก่อนส่ง รัน `npm run kb:check`
