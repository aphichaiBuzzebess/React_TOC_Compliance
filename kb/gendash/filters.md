- Global filter ใช้กรองทั้ง dashboard รวมถึงวันที่ (override :start และ :end) แล้ว query ใหม่
- ผูก filter กับ tab เดียวได้
- Cross-filter: คลิก chart หรือแถว table เพื่อกรอง widget อื่น
- Viewer filter ให้ผู้อ่านกรองเองได้
