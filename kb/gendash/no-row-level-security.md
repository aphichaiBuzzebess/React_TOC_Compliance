แยกสิทธิ์ได้ระดับ tenant และ dataset แต่ยังไม่มี row-level security ภายใน tenant เดียว ผู้ใช้ใน tenant เดียวกันที่เข้าถึง dataset ได้จะเห็นข้อมูลทุกแถวของ dataset นั้น

สถานะนี้มาจากการเทียบกับ Power BI เมื่อ 2026-10-05 โดยอ่านจากโค้ด ยังไม่ได้ตรวจซ้ำหลังจากนั้น
